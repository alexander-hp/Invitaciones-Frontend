🗺️ Guía de Integración Rápida con Sitios Web Externos

Aprende cómo conectar tu propia página web (Webflow, WordPress, Next.js, HTML) al backend de KyndraSoft para gestionar RSVP, álbum colaborativo, solicitudes DJ y pases de invitados.

1. Crear un Access Link de tipo integration_api

Genera un token de API para tu sitio web desde el dashboard de organizador:

curl -X POST https://tu-dominio.com/api/events/{eventId}/access-links \
  -H "Authorization: Bearer <tu-jwt>" \
  -H "Content-Type: application/json" \
  -d '{ "role": "integration_api", "label": "Mi Web Oficial", "days": 90 }'

2. Obtener la Configuración y Contenido del Evento

Consulta datos de novios, fecha, ubicación, música y módulos habilitados usando el slug del portal:

curl https://tu-dominio.com/api/external/{portalSlug}/config

3. Identificar a un Invitado por Email o Teléfono

curl -X POST https://tu-dominio.com/api/external/{portalSlug}/guest/identify \
  -H "Content-Type: application/json" \
  -d '{ "email": "invitado@email.com" }'

4. Enviar Confirmación RSVP

curl -X POST https://tu-dominio.com/api/external/{portalSlug}/rsvp \
  -H "Content-Type: application/json" \
  -d '{
    "guest": "<guestId>",
    "name": "Carlos Mendoza",
    "response": "confirmed",
    "companions": 1,
    "companionNames": ["Sofía Pérez"]
  }'

5. Embeber Widgets con iFrame

<!-- Widget RSVP Embebido -->
<iframe src="https://tu-dominio.com/embed/{portalSlug}/rsvp" width="100%" height="720" style="border:0"></iframe>

<!-- Widget Álbum Colaborativo -->
<iframe src="https://tu-dominio.com/embed/{portalSlug}/album" width="100%" height="720" style="border:0"></iframe>

<!-- Widget Mapa de Ubicaciones -->
<iframe src="https://tu-dominio.com/embed/{portalSlug}/map" width="100%" height="480" style="border:0"></iframe>
