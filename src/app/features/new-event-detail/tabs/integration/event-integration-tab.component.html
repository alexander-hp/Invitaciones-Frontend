🗺️ Guía Paso a Paso: Cómo Construir una Invitación Completa como KyndraSoft

Sigue este flujo paso a paso en tu propio código web para implementar una experiencia interactiva idéntica a nuestra plataforma.

1

Inicialización & Carga de Datos del Evento

Llama a GET /config y GET /invitation al cargar la página para obtener nombres de novios, fecha, hora, mapa de ubicación, código de vestimenta, música de fondo y estado de los módulos.

EndPoints: GET /config, GET /invitation, GET /itinerary
2

Identificación del Invitado & Token de Sesión

Si el evento usa lista cerrada (guest_list), solicita el email o teléfono del invitado y envía a POST /guest/identify. Guarda el guestSessionToken en localStorage o estado local para adjuntarlo en las siguientes peticiones.

EndPoints: POST /guest/identify, GET /my-status
3

Formulario RSVP & Asignación de Pases

Muestra la casilla de confirmación (Asistiré / No asistiré / Tal vez), límite de acompañantes devuelto en el Paso 2, menú y restricciones alimenticias. Al enviar a POST /rsvp, el sistema confirmará la asistencia y generará su Pase Digital QR.

EndPoints: POST /rsvp, GET /pass/:token
4

Módulos Interactivos (Música DJ, Álbum, Regalos & Libro de Visitas)

Integra el resto de características en la interfaz del invitado:

  • DJ Playlist: Usa POST /song-lookup para resolver enlaces de Spotify y POST /song-requests para enviar la propuesta con dedicatoria.
  • Álbum de Fotos: Permite tomar o seleccionar fotos del celular y subirlas mediante POST /album (multipart/form-data).
  • Sobre Digital & Regalos: Consume GET /gifts para renderizar los enlaces a tiendas y copiar la CLABE bancaria de 18 dígitos con un clic.
  • Libro de Visitas: Lee y publica comentarios con GET & POST /dedications.

💻 Código de Ejemplo JavaScript / TypeScript (Cliente Completo)

Snippet listo para copiar en tu proyecto React, Vue, Next.js o HTML nativo. 

const API_BASE = '{{ externalApiConfigUrl ? externalApiConfigUrl.replace('/config', '') : 'https://backend.tudominio.com/api/external/' + (event?.externalPortalSlug || 'slug') }}';
let guestToken = '';

// 1. Cargar Configuración del Evento
async function inicializarInvitacion() {
  const resConfig = await fetch(API_BASE + '/config');
  const config = await resConfig.json();
  
  const resDetalles = await fetch(API_BASE + '/invitation');
  const detalles = await resDetalles.json();

  console.log('Evento:', config.eventName, 'Fecha:', detalles.date);
}

// 2. Identificar Invitado por Email
async function identificarInvitado(email) {
  const res = await fetch(API_BASE + '/guest/identify', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email })
  });
  const data = await res.json();
  guestToken = data.guestSessionToken;
  return data; // Contiene guestId, guestName, companionLimit, assignedTable, assignedSeat
}

// 3. Enviar Confirmación RSVP
async function enviarRSVP(guestId, respuesta, acompanantes, comida) {
  const res = await fetch(API_BASE + '/rsvp', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + guestToken
    },
    body: JSON.stringify({ guest: guestId, response: respuesta, companions: acompanantes, dietaryRestrictions: comida })
  });
  return await res.json();
}

// 4. Solicitar Canción al DJ con Búsqueda Spotify
async function pedirCancionDJ(busqueda, dedicatoria) {
  const resLookup = await fetch(API_BASE + '/song-lookup', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ query: busqueda })
  });
  const cancion = await resLookup.json();

  await fetch(API_BASE + '/song-requests', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title: cancion.title, artist: cancion.artist, spotifyUrl: cancion.spotifyUrl, dedication: dedicatoria })
  });
}

// 5. Subir Foto al Álbum (Multipart Form-Data)
async function subirFotoAlbum(archivoImagen, comentario) {
  const formData = new FormData();
  formData.append('file', archivoImagen);
  formData.append('caption', comentario);

  const res = await fetch(API_BASE + '/album', {
    method: 'POST',
    headers: { 'Authorization': 'Bearer ' + guestToken },
    body: formData
  });
  return await res.json();
}

⚡ Consideraciones Técnicas & Buenas Prácticas

Recomendaciones optimizadas para garantizar rendimiento, seguridad y responsividad.

⏱️ Refresco de Datos (Polling)

Intervalo recomendado de 10 segundos (`10000ms`) para `my-status` y 15 segundos (`15000ms`) para álbum público y dedicatorias.

🖼️ Límites de Archivo

Límite máximo de 8 MB por fotografía. Formatos aceptados: image/jpeg, image/png, image/webp.

🔒 Permisos de iFrame

Incluye siempre allow="autoplay; camera; clipboard-write; encrypted-media" para reproductor, escaneo QR y portapapeles.
