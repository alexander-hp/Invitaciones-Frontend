🗺️ Guía Paso a Paso: Cómo Construir una Invitación Completa como KyndraSoft

Sigue este flujo de 4 pasos en tu propio código web para implementar una experiencia interactiva idéntica a nuestra plataforma.

1

Inicialización & Carga de Datos del Evento

Llama a GET /api/external/:portalSlug/config al cargar la página para obtener nombres de novios, fecha, hora, mapa de ubicación, código de vestimenta, música de fondo y estado de los módulos.

Endpoints: GET /api/external/:portalSlug/config, GET /api/external/:portalSlug/assets
2

Identificación del Invitado & Token de Sesión

Solicita el email o teléfono del invitado y envía a POST /api/external/:portalSlug/guest/identify. Guarda el guestSessionToken para adjuntarlo en las siguientes peticiones como Bearer Token.

Endpoints: POST /api/external/:portalSlug/guest/identify, GET /api/external/:portalSlug/my-status
3

Formulario RSVP & Asignación de Pases

Muestra la casilla de confirmación (Asistiré / No asistiré), límite de acompañantes devuelto en el Paso 2 y requerimientos alimenticios. Al enviar a POST /api/external/:portalSlug/rsvp, el sistema confirmará la asistencia.

Endpoints: POST /api/external/:portalSlug/rsvp
4

Módulos Interactivos (Música DJ, Álbum, Regalos & Libro de Visitas)

Integra las características en la interfaz del invitado:

  • DJ Playlist: Usa POST /song-lookup para resolver canciones y POST /song-requests para enviar la propuesta.
  • Álbum de Fotos: Permite tomar o seleccionar fotos y subirlas mediante POST /album.
  • Sobre Digital & Regalos: Consume GET /gifts para renderizar tiendas y copiar la CLABE bancaria.
  • Libro de Visitas: Lee y publica comentarios con GET & POST /dedications.

💻 Código de Ejemplo JavaScript / TypeScript (Cliente Completo)

Snippet listo para copiar en tu proyecto React, Vue, Next.js o HTML nativo. 

const API_BASE = '{{ externalApiConfigUrl ? externalApiConfigUrl.replace('/config', '') : 'https://backend.tudominio.com/api/external/' + (event?.externalPortalSlug || 'slug') }}';
let guestToken = '';

// 1. Cargar Configuración del Evento
async function inicializarInvitacion() {
  const resConfig = await fetch(API_BASE + '/config');
  const data = await resConfig.json();
  console.log('Evento:', data.event.title, 'Fecha:', data.event.date);
}

// 2. Identificar Invitado por Email
async function identificarInvitado(email) {
  const res = await fetch(API_BASE + '/guest/identify', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email })
  });
  const data = await res.json();
  guestToken = data.guestSessionToken;
  return data;
}

// 3. Enviar Confirmación RSVP
async function enviarRSVP(guestId, respuesta, acompanantes, comida) {
  const res = await fetch(API_BASE + '/rsvp', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + guestToken
    },
    body: JSON.stringify({ guest: guestId, response: respuesta, companions: acompanantes, dietaryRestrictions: comida })
  });
  return await res.json();
}
