📡 API REST Pública (Endpoints & JSON Schemas)

CORS Habilitado
Base Endpoint URL: {{ externalApiConfigUrl ? externalApiConfigUrl.replace('/config', '') : 'https://backend.tudominio.com/api/external/' + (event?.externalPortalSlug || 'slug') }}

GET /config

Obtiene la configuración pública del evento: títulos, novios, imágenes hero, audio principal y banderas de módulos activos. 

GET /api/external/{{ event?.externalPortalSlug || 'slug' }}/config
GET /assets?type=all

Obtiene los recursos multimedia filtrados por tipo (cover, carousel, gallery, audio). 

GET /api/external/{{ event?.externalPortalSlug || 'slug' }}/assets?type=all
POST /guest/identify

Identifica a un invitado por email, teléfono o token. Retorna datos de grupo, mesa, asiento y guestSessionToken. 

POST /api/external/{{ event?.externalPortalSlug || 'slug' }}/guest/identify
{ "email": "invitado@ejemplo.com" }
GET /my-status

Polling de actividad del invitado autenticado: confirmación RSVP, sus fotos subidas y solicitudes de canciones al DJ. 

GET /api/external/{{ event?.externalPortalSlug || 'slug' }}/my-status
Authorization: Bearer <guestSessionToken>
POST /rsvp

Registra o modifica la confirmación de asistencia, acompañantes, restricción alimenticia y selección de menú. 

POST /api/external/{{ event?.externalPortalSlug || 'slug' }}/rsvp
{ "guest": "id", "response": "confirmed", "companions": 2 }
POST /album

Subida de fotos multipart (multipart/form-data). Permite archivos JPG, PNG y WEBP hasta 8 MB. 

POST /api/external/{{ event?.externalPortalSlug || 'slug' }}/album
Content-Type: multipart/form-data (file: binary)
POST /song-lookup

Busca y resuelve automáticamente metadatos de canciones a partir de un enlace de Spotify, YouTube o texto. 

POST /api/external/{{ event?.externalPortalSlug || 'slug' }}/song-lookup
{ "query": "Earth Wind and Fire - September" }
POST /song-requests

Envía una solicitud de canción con dedicatoria a la lista del DJ del evento. 

POST /api/external/{{ event?.externalPortalSlug || 'slug' }}/song-requests
{ "title": "September", "artist": "Earth, Wind & Fire" }
